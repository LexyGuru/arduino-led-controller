# Arduino LED Controller 5.5.1-beta.1

## Kiadás összefoglaló

A 5.5.1-beta.1 a V5.5 alkalmazás javító béta kiadása. A firmware külön verziózott komponens, ezért változatlanul 5.0.0-beta.8 marad, a Direct API pedig 1.0.0.

## Fő javítások

- macOS Dock ikon a tényleges alkalmazás Light/Dark megjelenését követi;
- Android és iOS clean-build ikon pipeline kanonikus V5 ikonforrásból;
- iOS/iPadOS natív Light és Dark AppIcon appearance;
- OpenAPI és generált TypeScript verziósurface-ek egységesítése;
- release- és current-version contractok normalizálása;
- Python teszt-szintaxisellenőrzés bytecode/cache maradvány nélkül.

## Kompatibilitás

- Theme Engine 2.0 változatlanul támogatott.
- App Update Center 1.0 változatlanul támogatott.
- LXC shared runtime és release pipeline változatlanul támogatott.
- A `main` ág nem módosul.
- Firmware: `5.0.0-beta.8` — not modified / nem módosul.
