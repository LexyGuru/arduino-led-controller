# 3.0.13 – OTA listener és diagnosztika

- Az OTA feltöltő verziója megjelenik a valós idejű konzolban.
- Az arduinoOTA részletes (`-v`) módban indul.
- A Tauri feltöltés előtt meghívja az Arduino `/api/ota/restart` végpontját.
- A listener újraindítása után 2,5 másodperc stabilizálási idő következik.
- A „Connecting to board ... failed” hiba külön hálózati diagnózist és `nc` tesztparancsot kap.
- A csomag tartalmazza a 4.1.14 firmware-t az OTA listener újraindító API-val.
