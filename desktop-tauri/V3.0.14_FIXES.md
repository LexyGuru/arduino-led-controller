# 3.0.14 – teljesen önálló, beépített OTA

- A külső `arduinoOTA` futtatható fájl használata megszűnt.
- A Tauri/Rust backend közvetlen `POST /sketch` HTTP-kéréssel tölti fel a binárist.
- Basic Auth felhasználónév: `arduino`; a jelszó az alkalmazás titkos tárából érkezik.
- Kötelező `Content-Length` és `application/octet-stream` fejléc.
- 4096 bájtos adatblokkok és 5%-os valós idejű folyamatjelzés.
- A GitHub-letöltés és SHA-256 ellenőrzés után, közvetlenül a feltöltés előtt indul újra az OTA-listener.
- Nem szükséges Arduino IDE, Arduino CLI, Proxmox, Node szerver vagy külső OTA-bináris.
- A macOS alkalmazás saját helyi hálózati jogosultságát használja.
