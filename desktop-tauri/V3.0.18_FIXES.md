# 3.0.18 javítások

- macOS Terminal OTA mindig az Arduino `/api/status` válaszából frissen kiolvasott `ipAddress` és `otaPort` értéket használja.
- DHCP-címváltozás vagy másik Arduino esetén nincs kézzel beégetett OTA IP.
- A GitHub eredeti `ArduinoLedController.ino.bin` fájlneve helyben is megmarad.
- A Terminal 15 alkalommal ellenőrzi az OTA-portot az arduinoOTA indítása előtt.
- Zárt portnál az alkalmazás nem indít sikertelen feltöltést, hanem pontos listener-hibát ír ki.
- A 4.1.15 ismert `/api/ota/restart` problémája miatt ennél a verziónál a kliens kihagyja az end/begin újraindítást.
- Újabb firmware-eknél először `/api/ota/prepare`, majd kompatibilitási tartalékként `/api/ota/restart` használható.
