# 3.0.15 – DDNS OTA és macOS Terminal feltöltés

## Fő javítás

A Tauri többé nem használja automatikusan az Arduino `/api/status` válaszában szereplő belső `ipAddress` értéket OTA-célként. Az OTA-cél külön konfigurálható:

- OTA DDNS/IP-cím
- OTA külső TCP-port
- feltöltési mód: automatikus, beépített vagy macOS Terminal
- arduinoOTA program útvonala

Ha az OTA-cím mező üres, a távoli Arduino DDNS/IP mező értéke lesz használva.

## macOS Terminal mód

Az alkalmazás `.command` fájlt készít az alkalmazás saját adatkönyvtárában, majd a macOS Terminalban indítja el az `arduinoOTA` programot. A kimenetet naplófájlba irányítja, amelyet a Tauri valós időben visszaolvas az OTA-konzolba.

Az OTA-jelszó külön, `0600` jogosultságú ideiglenes fájlba kerül. A Terminal-parancs indulásakor a jelszófájl törlődik, a parancsfájl pedig a folyamat végén saját magát is eltávolítja.

## Hálózati követelmény

A No-IP/DDNS név önmagában nem továbbít portot. A routerben az alkalmazásban megadott külső OTA TCP-portot az Arduino belső `65280/TCP` portjára kell irányítani.

Példa:

```text
lexyguruhome.ddns.net:65280
        ↓ router TCP port forward
10.0.0.123:65280
```
