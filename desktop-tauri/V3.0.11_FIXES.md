# Arduino LED Controller Desktop 3.0.11

## Valós idejű OTA-konzol

A Firmware OTA oldalon a telepítés minden lépése azonnal megjelenik:

- OTA-jelszó és feltöltő ellenőrzése
- GitHub `firmware-latest` kiadás lekérése
- firmware-bináris letöltése és mérete
- SHA-256 ellenőrzés eredménye
- ideiglenes firmware-fájl helye
- kiválasztott Arduino OTA-cél
- az `arduinoOTA` folyamat PID-je
- az `arduinoOTA` stdout és stderr kimenete
- százalékos feltöltési állapot, amikor a feltöltő kiírja
- tíz másodpercenkénti életjel, ha a feltöltő nem ad kimenetet
- Arduino újraindulásának és firmware-verziójának ellenőrzése
- teljes és részletes hibaüzenet

Az OTA folyamat 180 másodperces biztonsági időkorlátot kapott. Ha a külső
`arduinoOTA` folyamat beragad, az alkalmazás leállítja és a konzolban kiírja
a rendelkezésre álló kimenetet.

A Tauri backend az `ota-progress` eseményen küldi a folyamatot a React
felületnek. A listener az alkalmazás teljes futása alatt aktív, ezért a hosszú
Rust parancs közben is frissül a kezelőfelület.
