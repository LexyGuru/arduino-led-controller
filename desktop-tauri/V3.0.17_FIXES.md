# 3.0.17 javítások

- A GitHub Release eredeti firmware-fájlneve megmarad (`ArduinoLedController.ino.bin`).
- A helyben mentett fájlt az alkalmazás visszaolvassa, és újra ellenőrzi a méretét és SHA-256 értékét.
- Az OTA konzol egyértelműen megkülönbözteti a forrás URL-t és a helyi cache útvonalat.
- DDNS/No-IP cél esetén külön porttovábbítási figyelmeztetés jelenik meg.
- `Connecting to board ... failed!` hibánál a program közli, hogy a kapcsolat még a bináris feldolgozása előtt bukott el.
- A Beállítások pontosítják, hogy az OTA-port a router külső portja, amely a belső `10.0.0.123:65280` címre mutat.
