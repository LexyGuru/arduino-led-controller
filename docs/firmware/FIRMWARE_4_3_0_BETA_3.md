# Firmware 4.3.0-beta.3

A `5.0.0-beta.4` asztali alkalmazás firmware-párja.

- Direct API: `1.0.0`
- Board: Arduino UNO R4 WiFi
- OTA-port: `65280`
- Csatorna: `beta`
- Release metadata: `firmware/firmware-release.json`

A kiadás megtartja a 4.3.0-beta.2 gyorsított HTTP-profilt, az A/B EEPROM-tárolást és a tranzakciós schedule-kezelést. A Beta.4 kiadási kapu a firmware binárist, SHA-256 fájlt és gépi manifestet együtt ellenőrzi.
