# Arduino LED Controller 5.7.0-beta.4 — Installation Guide

Application `5.7.0-beta.4`, Firmware `5.0.1-beta.1` Beta, Direct API `1.0.0`.

Existing Beta LXC installs update through `arduino-led-controller-update.service`. Shared LXC settings persist server-side and autosave.

Use the BETA firmware channel for `5.0.1-beta.1`. OTA strip feedback: blue in-progress latch, green successful reboot, red error.
