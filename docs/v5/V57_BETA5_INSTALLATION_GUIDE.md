# Arduino LED Controller 5.7.0-beta.5 — Installation Guide

Application `5.7.0-beta.5`, Firmware `5.0.1-beta.1` Beta, Direct API `1.0.0`.

Existing Beta installations update through the normal Beta application updater/release path.

Firmware updates are presented through the single canonical OTA2 interface. Native Rust OTA, macOS Terminal fallback, reboot confirmation, firmware-version verification and schedule-persistence verification remain available.

Use the BETA firmware channel for `5.0.1-beta.1`. A successful OTA operation must finish at `100% / Kész`.
