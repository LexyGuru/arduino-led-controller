# Arduino LED Controller 5.8.0-beta.1 — Development Notes

## Beta.1 — Dynamic LED Hardware Topology foundation

- Application development line: `5.8.0-beta.1`.
- Firmware development line: `5.1.0-beta.1`.
- Direct API: `1.0.0`.
- Persistent per-strip LED counts with firmware-defined read-only physical pins.
- Stable hardware identities `LX001`, `LX002`, `LX003`.
- Direct API topology read/write foundation with A/B EEPROM persistence and generation conflict protection.
- Visual 3.1 consumes real pin/count metadata from Arduino status.
- Settings gains a 1–300 LED per-strip hardware configuration editor.
- No commit, push or release is performed by V723.
