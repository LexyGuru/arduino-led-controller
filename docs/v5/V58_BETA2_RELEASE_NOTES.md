# Arduino LED Controller V5.8 Beta.2 — Test Build Notes

> **TEST BUILD ONLY — NO GITHUB RELEASE / NO TAG**

Application: `5.8.0-beta.2`
Firmware: `5.1.0-beta.2`
Direct API: `1.0.0`

## Included changes

- Separate mobile schedule workspace instead of compressed desktop layout.
- All seven weekdays visible simultaneously on mobile.
- Selected-day schedules shown as full-width mobile event cards.
- New/edit schedule flow uses a full-viewport mobile editor.
- LED topology saves show old → new counts and firmware revision.
- Firmware topology changes emit localized success/error log events.
- Current-version regression contracts are dynamic instead of pinned to Beta.1.

## Verification purpose

This commit is intended to trigger the normal GitHub build pipeline so the
generated application artifact can be downloaded and tested on real devices.
