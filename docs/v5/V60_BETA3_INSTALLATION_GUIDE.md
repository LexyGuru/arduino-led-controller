## Language packs

English remains embedded and cannot be removed. Open Settings → Language to use
the searchable Language Pack 2.1 catalog. Filter by Western Europe, Central &
Eastern Europe, or Asia.

Downloaded packs are stored locally and remain available offline. Downloads,
updates and reinstalls require internet access.

Every pack is checked for:
- JSON integrity and duplicate keys
- schema and language identity
- application compatibility
- maximum size
- SHA-256
- exact English-master key parity
- placeholder parity
- non-empty translated values

The selected installed language persists after application restart.
