# Arduino LED Controller 5.7.0-beta.4 — Release Notes

## Beta.4 — LXC persistence + OTA LED feedback

- LXC shared settings are server-side persistent and autosave immediately.
- OTA2 channel/version/post-verify fixes are preserved.
- Firmware `5.0.1-beta.1` Beta.
- Physical OTA feedback on all three WS2812B strips: blue latched before OTA transfer, green after successful reboot, red after OTA error.
- Direct API `1.0.0`, Theme Engine `2.0`, Core UI `3.0`.
