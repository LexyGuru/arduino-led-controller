# Arduino LED Controller 5.0.0-beta.1

A Beta.1 alkalmazás a végleges `4.3.0-beta.1` firmware és Direct API `1.0.0` alapjára épül.

## Firmware

- fejlécalapú eszközhitelesítés;
- A/B EEPROM konfiguráció és schedule;
- 60 rekordos tranzakciós schedule;
- lapozott visszaolvasás;
- desktop OTA;
- védett remote reboot;
- teljes hardverkapu.

## Következő fejlesztési fókusz

A firmware lezárult. A következő Beta munka a Tauri alkalmazás egyszerűsítése, direct Arduino-first UX kialakítása és az opcionális szerver/LXC funkciók elkülönítése.
