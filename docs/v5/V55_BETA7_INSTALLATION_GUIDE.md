# V5.5.1 Beta.7 Installation Guide

Install application `5.5.1-beta.7` from the Beta updater/release.

Firmware remains `5.0.0-beta.10`.

On macOS, keep a working `arduinoOTA` available at the configured path,
`/usr/local/bin/arduinoOTA`, `/opt/homebrew/bin/arduinoOTA`, or the bundled resource.
When native OTA cannot reach the local Arduino socket, the app automatically opens
Terminal and continues the OTA there.
