# Arduino LED Controller V5.5.1 Beta.2 – Telepítési útmutató

## Verziók
- Alkalmazás: `5.5.1-beta.2`
- Firmware: `5.0.0-beta.9`
- Direct API: `1.0.0`

## Platformok
macOS, Windows, Linux, Android, iOS/iPadOS és Debian 13 LXC.

## Firmware
A firmware a dedikált Beta firmware-katalógusban jelenik meg. Desktopon a beépített OTA és a
külső `.bin` feltöltés is használható. Downgrade kizárólag Restore útvonalon történik.
