# Arduino LED Controller 5.6.1-beta.4 — installation guide

- Application: `5.6.1-beta.4` Beta
- Firmware: `5.0.0-beta.10`
- Direct API: `1.0.0`
- Branch: `next/v5-rearchitecture`

P1 Beta.4 hardens GitHub Actions Linux/Tauri dependency installation. Firmware behavior is unchanged. Use only assets attached to the `v5.6.1-beta.4` prerelease. After install verify application identity, updater channel separation, Direct API `X-Device-Key`, firmware `5.0.0-beta.10`, and the frozen macOS OTA contract.
