# Arduino LED Controller 5.7.0-beta.3 — Installation Guide

Application `5.7.0-beta.3`, Firmware `5.0.0`, Direct API `1.0.0`, Theme Engine `2.0`, Core UI `3.0`.

This hotfix keeps the firmware source unchanged. After installing the 5.7.0-beta.3 desktop build, select the intended firmware update channel in Settings:
- `STABLE` resolves Stable firmware artifacts only.
- `BETA` resolves Beta firmware artifacts only.

No firmware source rebuild is part of this application hotfix.
