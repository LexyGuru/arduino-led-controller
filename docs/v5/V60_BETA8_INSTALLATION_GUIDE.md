# 6.0.0-beta.8 installation guide

Application: **6.0.0-beta.8**
Firmware: **5.1.0-beta.4**
Direct API: **1.2.0**

This is an application-only OTA lookup hotfix.

If firmware `5.1.0-beta.4` is already installed, no firmware update is required.
If an older Beta firmware is installed, the repaired desktop exact-version lookup can install `5.1.0-beta.4` from the dedicated Beta firmware release.
