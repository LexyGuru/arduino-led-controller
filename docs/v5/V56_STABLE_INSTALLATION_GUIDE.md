# Arduino LED Controller 5.6.1 — Stable installation guide

## Versions
- Application: `5.6.1`
- Firmware: `5.0.0`
- Direct API: `1.0.0`

Use the Stable application updater channel or the installers attached to GitHub release `v5.6.1`.
Firmware Stable `5.0.0` must be published through the separate firmware Stable workflow.
The application and firmware release workflows remain independent.
