# Arduino LED Controller V5.5.1 Beta.1 – Telepítési útmutató

## Verziók

- Alkalmazás: `5.5.1-beta.1`
- Firmware: `5.0.0-beta.8`
- Direct API: `1.0.0`

## Platformok

A kiadás macOS, Windows, Linux, Android, iOS/iPadOS és Debian 13 LXC környezetet céloz.

## Mobil ikonok

Az Android és iOS ikonok clean build során a kanonikus V5 runtime ikonforrásokból készülnek. iOS/iPadOS alatt külön Light és Dark AppIcon appearance kerül az asset catalogba.

## Megjegyzés

A firmware külön release-folyamatban marad; ez az alkalmazásverzió-emelés nem módosítja a `5.0.0-beta.8` firmware-t.
