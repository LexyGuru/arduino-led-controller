# Arduino LED Controller 6.0.0-beta.8

Application hotfix release.

## Versions

- Application: `6.0.0-beta.8`
- Firmware: `5.1.0-beta.4`
- Direct API: `1.2.0`

## Fixed

The desktop OTA exact-version installer now resolves firmware from the dedicated channel-aware firmware release instead of relying on the generic GitHub release-list window.

This fixes the false error:

`A(z) 5.1.0-beta.4 firmware nem található a(z) beta firmware-csatornán.`

The corrected path was verified with a real successful OTA installation, SHA-256 validation, reboot confirmation via bootGeneration, and schedule persistence verification.
