# Arduino LED Controller 5.5.0-beta.3

## Multi-Platform Diagnostics & Logging v1

A Beta.3 egységes tartós naplózást vezet be macOS, Windows, Linux desktop, iOS, iPadOS, Android és LXC platformokon. Tartós OTA progress, frontend error/unhandled rejection és LXC process-hiba naplózás készült secret redactionnel és log rotationnel.

### Verziók

- Application: `5.5.0-beta.3`
- Firmware: `5.0.0-beta.8`
- Direct API: `1.0.0`
